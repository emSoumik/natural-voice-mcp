# word bank

---

## words that sound like this voice

build, make, ship, try, fix, learn, teach, show, share, help, figure out, put together, went a step further, break into, get comfortable with, real, simple, clear, actually useful, everyday, workflow, taste, craft, idea, thing, stuff (levels 1 and 3)

## swaps

| instead of | use |
|---|---|
| utilize, leverage | use |
| facilitate | help, run |
| implement | build, add, set up |
| endeavor, embark on | start, try |
| delve into, dive deep | look at, get into, dig into |
| showcase | show |
| demonstrate | show |
| enhance, elevate | improve, make better |
| foster, cultivate | build, grow |
| empower | help, let |
| harness, unlock | use, open up |
| navigate (a challenge) | deal with, work through |
| journey | (name the actual thing: degree, project, year) |
| passionate about | (show it: what you built or did) |
| innovative, cutting edge | (describe what's new) |
| robust, seamless | (say what works well) |
| impactful | (name the impact) |
| stakeholders | people, users, the team |
| learnings | lessons, what i learned |
| upskill | learn |
| synergy, alignment | (rephrase plainly) |
| additionally, furthermore, moreover | also, and, (new sentence) |
| however (sentence opener) | but |
| in order to | to |
| due to the fact that | because |
| prior to | before |
| a number of | some, a few, (the number) |
| is able to | can |
| at this point in time | now |
| I am writing to express my interest | I'd love to be considered for |
| I hope this email finds you well | (delete) |
| please do not hesitate to reach out | happy to share more |
| I look forward to hearing from you | thanks for your time |
| thrilled / excited to announce | (just announce it) |
| humbled | (delete) |

## banned phrases

- at the end of the day
- it's important to note / it's worth noting
- it goes without saying
- that being said / having said that
- in terms of
- when it comes to
- in today's fast paced world
- the power of
- a testament to
- plays a crucial role
- game changer
- the future is bright
- this is just the beginning
- let that sink in
- here's the thing
- the best part?
- i'm excited to share
- stay tuned
- agree? / thoughts? (as a closer)
