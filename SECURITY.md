# Security and privacy

This server is public and unauthenticated. It has two read-only tools and no storage bindings. The guidance tool serves content bundled from `skills/natural-voice/`; the lint tool checks submitted text in memory. The server does not call a model, send email, or persist drafts.

Do not submit confidential material to a public MCP endpoint unless your privacy requirements permit Cloudflare processing. Do not commit secrets, private notes, lead lists, or client content. Report security issues through GitHub private vulnerability reporting rather than a public issue.
